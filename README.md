# Liga en Rondas

Organiza partidos individuales o equipos fijos: cruces sin repetir, descansos por ronda y horarios relativos para varias pistas. Gratis y sin registro.

GitHub Pages: main, raiz. https://ilga25.github.io/liga-en-rondas/

Fuentes estaticas sin dependencias. Pruebas del motor: work/ten-tools/check.cjs. Guia propia, privacidad y sitemap incluidos. Sin garantia de trafico, indexacion, aprobacion publicitaria o ingresos.
